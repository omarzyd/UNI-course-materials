From state s: action a1 (reward 10) with probability 0.2, action a2 (reward 2) with probability 0.8. γ = 0 and next states have value 0. What is V(s)?

V(s) = Σa π(a|s) [r + γ V(s′)] = 0.2 × (10 + 0) + 0.8 × (2 + 0) = 2 + 1.6 = 3.6

Actions و Transitionsانقل الـ disk اللي فوق من peg لـ peg، بشرط ما يتحطش على disk أصغر منه. والـ transition deterministic.
Reward1 لو وصلت (C,C,C)، و0 غير كده. وγ = 1.
الـ naive policyحرّك الـ disk الأصغر للـ peg اللي بعده clockwise، ولو مش ممكن حرّك الـ disk اللي بعده.
الملاحظة المهمةالـ disk الأصغر دايماً فوق، فدايماً ينفع يتحرك. يعني الشرط «لو مش ممكن» عمره ما بيحصل، والـ policy بتلف الـ disk 1 في دواير، والـ disks 2 و3 ما بيتحركوش أبداً. اتفرّج:

الـ value function بعد iteration واحدة

v1(s) = R(s, π(s)) + γ · v0(s′), v0 = 0, γ = 1

بما إن v0 = 0 في كل حتة، يبقى v1(s) = R(s, π(s))، وده 1 بس لو الـ action بتاع الـ policy بيوصّل للهدف على طول. ومع clockwise A → B → C → A، الـ state الوحيدة هي (B,C,C): الـ disk 1 بيروح من B لـ C. يعني v1(B,C,C) = 1، والـ 26 state التانيين قيمتهم 0.

ولو كمّلت iterations: القيمة 1 هتوصل كمان لـ (A,C,C)، عشان الخطوة اللي بعدها بتوديها (B,C,C)، وبس كده. أي state الـ disk 2 أو 3 فيها مش على C هتفضل 0 للأبد. وده بيثبت إن الـ naive policy عمرها ما هتحل اللعبة من البداية. ولو اخترت clockwise بالعكس (A → C → B)، الـ state اللي قيمتها 1 هتبقى (A,C,C). فقول اتجاهك في الحل.
