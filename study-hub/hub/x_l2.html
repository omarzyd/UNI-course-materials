S&B Ex. 3.9 لما الـ rewards ملهاش آخر

Suppose γ = 0.9 and the reward sequence is R1 = 2 followed by an infinite sequence of 7s. What are G1 and G0?
  1. من t = 1 كل الـ rewards 7: G1 = 7 + 0.9·7 + 0.9²·7 + … = 7 / (1 − 0.9) = 70
  2. G0 = R1 + γ G1 = 2 + 0.9 × 70 = 65

القانون اللي بتستخدمه: Σk≥0 γk = 1 / (1 − γ) لما γ < 1. وده بالظبط ليه γ أقل من 1 بتخلّي الـ return محدود في الـ continuing tasks.

S&B 3.4 episodic وcontinuing في نوتيشن واحدة

الـ episode اللي بتخلص بنعتبرها بتدخل absorbing state: بتفضل فيه للأبد، وكل الـ rewards بعدها صفر. كده نفس القانون Gt = Σ γk Rt+k+1 بيشتغل للنوعين. والشرط الوحيد: ما ينفعش T = ∞ وγ = 1 مع بعض.

Example 3.4 الـ pole balancing: لو episodic بـ +1 كل خطوة، يبقى الـ return = عدد الخطوات. ولو continuing بـ −1 عند الوقوع وصفر غير كده، يبقى الـ return = −γK (K = عدد الخطوات قبل الوقوع). وفي الحالتين، تفضل واقف أطول يعني return أحسن.

Assignment 2 الـ paper response بتاع الأخبار: إجابات نموذجية

  1. الـ terms زي ما الـ paper عرّفها: الـ agent = الـ algorithm (LinUCB) اللي بيختار الخبر. الـ environment = الزوار. الـ state/context = features الزائر مع features كل خبر (xt,a). الـ action = arm = الخبر اللي يتعرض. الـ reward/payoff = 1 لو حصل click، و0 غير كده. يعني الـ expected reward = الـ CTR.
  2. ليه bandit: كل trial مستقلة. الخبر اللي اتعرض مش بيغيّر مين الزائر الجاي ولا الـ context بتاعه. عشان يبقى full RL، لازم الـ action يغيّر الـ state الجاية، زي إن نفس المستخدم يرجع وتجربته تتأثر بالأخبار اللي شافها قبل كده، والـ reward يبقى على الـ session كلها.
  3. Limitation في الـ click: الـ click مش رضا. ممكن يكافئ الـ clickbait، وبيتأثر بمكان الخبر في الصفحة (position bias). وكمان مش بيقيس إن الزائر قرا الخبر أو رجع الموقع تاني.
فكرة من الـ paper ممكن تتسأل فيهاالـ offline evaluation بالـ replay: عندهم logs اتعرض فيها الخبر بشكل عشوائي. بيعدّوا على الـ log، ولما الـ algorithm يختار نفس الخبر اللي اتعرض فعلاً، بياخدوا الـ click ده ويحسبوه. وده unbiased بس عشان الـ logging كان random (i.i.d.). ولو الـ log جه من policy تانية متحيزة، التقييم يبقى متحيز. والنتيجة: LinUCB جاب clicks أكتر بـ 12.5% على أكتر من 33 مليون event.
